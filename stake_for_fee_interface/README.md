# stake_for_fee_interface

Rust interface for the stake-for-fee (M3M3) program, generated by Anchor `declare_program!` from [`idls/stake_for_fee.json`](./idls/stake_for_fee.json).

Program ID: `FEESngU3neckdwib9X3KWqdL7Mjmqk9XNp3uh5JbP4KP`

> **Deprecated.** `initialize_vault`, `initialize_stake_escrow`, `stake`, `request_unstake` and `cancel_unstake` always fail with `Deprecated`. Stakers exit with `withdraw_stake`, existing unstake requests are withdrawn with `withdraw`, and `claim_fee` / `claim_fee_crank` keep working.

## Install

Requires `anchor-lang` 1.2.1 and Rust 1.89 or newer.

```toml
[dependencies]
anchor-lang = "1.2.1"
stake_for_fee_interface = { git = "https://github.com/MeteoraAg/stake-for-fee-sdk" }
```

If your program generates its IDL, forward the `idl-build` feature:

```toml
[features]
idl-build = ["anchor-lang/idl-build", "stake_for_fee_interface/idl-build"]
```

## What is exported

| Path | Content |
| --- | --- |
| `ID` | Program ID |
| `program::StakeForFee` | Program type, for `Program<'info, StakeForFee>` |
| `accounts` | `FeeVault`, `StakeEscrow`, `Unstake`, `TopListMetadata`, `FullBalanceListMetadata` |
| `types` | Structs used by the accounts and instruction args |
| `events` | Events emitted by the program, such as `ClaimFeeSucceed` and `WithdrawStakeSucceed` |
| `error::StakeForFeeError` | Program errors |
| `cpi`, `cpi::accounts` | CPI helpers, one function and one accounts struct per instruction |
| `client::accounts`, `client::args` | Off-chain instruction builders |
| `parsers` | Off-chain `Account`, `Event` and `Instruction` parsers |

PDA helpers (vault, top staker list, full balance list, event authority) are in the [`common`](../common) crate.

## Read an account

```rust
use anchor_lang::AccountDeserialize;
use stake_for_fee_interface::accounts::StakeEscrow;

fn stake_amount(data: &[u8]) -> anchor_lang::Result<u64> {
    let stake_escrow = StakeEscrow::try_deserialize(&mut &data[..])?;
    Ok(stake_escrow.stake_amount)
}
```

`parsers::Account::parse(data)` decodes any program account and returns it as an enum variant.

## CPI from an Anchor program

Example with `withdraw`. Every instruction follows the same pattern: `cpi::<instruction>` with `cpi::accounts::<Instruction>`. The example also uses `anchor-spl = "1.2.1"` for the token accounts (add `anchor-spl/idl-build` to your `idl-build` feature too).

```rust
use anchor_lang::prelude::*;
use anchor_spl::token::{Token, TokenAccount};
use stake_for_fee_interface::{
    accounts::{FeeVault, StakeEscrow, Unstake},
    program::StakeForFee,
};

#[derive(Accounts)]
pub struct WithdrawUnstake<'info> {
    #[account(mut)]
    pub unstake: AccountLoader<'info, Unstake>,
    #[account(mut)]
    pub stake_escrow: AccountLoader<'info, StakeEscrow>,
    #[account(mut)]
    pub stake_token_vault: Account<'info, TokenAccount>,
    #[account(mut)]
    pub vault: AccountLoader<'info, FeeVault>,
    #[account(mut)]
    pub user_stake_token: Account<'info, TokenAccount>,
    #[account(mut)]
    pub owner: Signer<'info>,
    /// CHECK: validated by the stake-for-fee program
    pub event_authority: UncheckedAccount<'info>,
    pub stake_for_fee_program: Program<'info, StakeForFee>,
    pub token_program: Program<'info, Token>,
}

pub fn handle_withdraw_unstake(ctx: Context<WithdrawUnstake>) -> Result<()> {
    let accounts = stake_for_fee_interface::cpi::accounts::Withdraw {
        unstake: ctx.accounts.unstake.to_account_info(),
        stake_escrow: ctx.accounts.stake_escrow.to_account_info(),
        stake_token_vault: ctx.accounts.stake_token_vault.to_account_info(),
        vault: ctx.accounts.vault.to_account_info(),
        user_stake_token: ctx.accounts.user_stake_token.to_account_info(),
        owner: ctx.accounts.owner.to_account_info(),
        token_program: ctx.accounts.token_program.to_account_info(),
        event_authority: ctx.accounts.event_authority.to_account_info(),
        program: ctx.accounts.stake_for_fee_program.to_account_info(),
    };

    stake_for_fee_interface::cpi::withdraw(CpiContext::new(
        ctx.accounts.stake_for_fee_program.key(),
        accounts,
    ))
}
```

Use `CpiContext::new_with_signer` when the stake owner is a PDA of your program.

## Build an instruction off-chain

```rust
use anchor_lang::{
    prelude::Pubkey, solana_program::instruction::Instruction, InstructionData, ToAccountMetas,
};
use stake_for_fee_interface::client;

pub fn withdraw_ix(accounts: client::accounts::Withdraw) -> Instruction {
    Instruction {
        program_id: stake_for_fee_interface::ID,
        accounts: accounts.to_account_metas(None),
        data: client::args::Withdraw {}.data(),
    }
}

pub fn event_authority() -> Pubkey {
    Pubkey::find_program_address(&[b"__event_authority"], &stake_for_fee_interface::ID).0
}
```
